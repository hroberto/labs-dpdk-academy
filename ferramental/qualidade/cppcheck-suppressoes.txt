// 1. MACROS DO GOOGLETEST
// O cppcheck nao expande `TEST(Suite, Caso)` e reporta `syntaxError` na linha da

// 2. CABECALHO C COMPILADO TAMBEM COMO C++
// `statistics.h` e `cadeia.h` sao C e sao incluidos por unidades C++ (os testes
// L1 em GoogleTest e a alternativa em C++23). O cppcheck aplica entao regras de
// C++ a codigo C: `cstyleCast` (cast em C e cast em C) e `passedByValue`
// (sugerir referencia const em C nao compila). Trocar para satisfazer o
// analisador quebraria o lado C, que e o principal.

cstyleCast:docs/01-fundamentos/medicoes/cadeia.h
