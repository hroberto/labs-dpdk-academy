# Histórico de coletas — isolamento de CPU

Vazio por decisão de 24/09/2026. As coletas anteriores foram removidas porque
duas execuções do mesmo dia colidiram no mesmo nome e uma delas ficou rotulada
com a configuração de memória errada. Elas continuam na história do git, no
commit anterior a esta remoção.

O que as substitui é o roteiro das quatro células — memória 4800 e 6000 MT/s
contra canal único e duplo — com o nome da coleta carregando hora e minuto e
a configuração da BIOS conferida pelo programa antes de medir.

Enquanto esta pasta estiver vazia, os números do README deste tópico descrevem
coletas que não estão arquivadas aqui. É estado declarado, não esquecimento.
