
== The SPSC ring in C++23, measured ==

  ring of 4096 slots; full enqueue+dequeue cycle
  ONE thread, NO contention: same condition as custo-anel.c, so
  that the two numbers are comparable
  samples: 25, each with 200000 operations

  batch    unitary (ns/obj)    bulk (ns/obj)
  -----    ----------------    -------------
  1                3.376 ns         2.827 ns
  8                1.104 ns         0.659 ns
  32               1.210 ns         0.588 ns
  128              1.159 ns         0.531 ns

  'unitary' is a loop of n single-element calls: n release
  stores. 'bulk' is one span call: ONE release store. The C side
  uses rte_ring_enqueue_bulk, so 'bulk' is the paired column.

  Compare with the same table on the C side, in
  docs/03-mempool-ring-mbuf/medicoes/custo-anel.c: same condition,
  same number of operations, same statistic.
