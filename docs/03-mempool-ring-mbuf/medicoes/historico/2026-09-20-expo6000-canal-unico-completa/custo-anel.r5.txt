== The price of the ring's generality ==

  ring of 4096 slots; full enqueue+dequeue cycle
  ONE lcore, NO contention: what is measured is the atomic instruction,
  not the cache-line migration between cores
  samples: 25, each with 200000 operations

  batch      SP/SC (ns/obj)   MP/MC (ns/obj) MP/MC cost
  -----      --------------   -------------- -----------
  1                1.626 ns         8.241 ns       407%
  8                0.573 ns         1.283 ns       124%
  32               0.404 ns         0.484 ns        20%
  128              0.372 ns         0.307 ns       -18%

  The MP/MC cost does not vanish for lack of contention: the atomic
  operation runs either way. What batching does is dilute that fixed
  cost over more objects -- the same logic that already appeared in
  batch size and in the cross-core traversal.

== _bulk and _burst are not synonyms ==

  ring requested with 16 slots; real capacity: 15
  (one slot is reserved to tell full apart from empty)

  enqueued 12 into an empty ring ........ burst accepted 12, free=3
  asking for 12 more with only 3 free:
    _bulk  accepted 0  <- all or nothing: NOTHING went in
    _burst accepted 3  <- partial: 3 went in, 9 stayed out

  The practical consequence is in _burst's return value: the 9 objects
  that did NOT go in are still yours. Whoever ignores that number and
  treats them all as enqueued loses ownership of them -- and, if they came
  from a mempool, the pool drains silently until the pipeline stalls.
